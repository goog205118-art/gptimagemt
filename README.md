# GPT Image 个人工作室

使用自己的 OpenLux Key 生成、编辑和管理图片。浅色界面，支持参考图拖入/粘贴、并行任务、失败重试、版本分支、局部蒙版、自然扩图、项目/预设、对比与导出。

## 部署到 Vercel

1. 在 Vercel 中导入本仓库。
2. Root Directory 保持仓库根目录，Framework 选择 **Vite**。
3. 构建命令 `npm run build`，输出目录 `dist`，安装命令 `npm ci`。仓库内的 `vercel.json` 已配置这些值。
4. Node.js 选择 **22.x**，然后部署。
5. 打开站点，在「连接与偏好」填写自己的 API Key。默认地址为 `https://api.openlux.ai/v1`。

**不需要把 API Key 或账户查询令牌配置为 Vercel 环境变量，也不要写入源代码。** 每个浏览器使用自己填写的连接。官方地址的模型列表、额度查询和 Agent 规划通过本站接口转发；凭据仅用于本次请求，应用不在服务端存储或记录凭据。原始参考图和图片生成直接从浏览器发往填写的服务商；Agent 只接收压缩参考预览。

Vercel 的函数请求/响应大小存在限制，因此图片上传、生成和下载没有经过函数转发；自定义服务商需要允许浏览器跨域连接。大尺寸图片或复杂生成的等待时长由输入区「任务」设置控制，超时与断网不会自动重复付费生成。[Vercel 函数限制](https://vercel.com/docs/functions/limitations)

## 本地开发

```sh
npm ci
npm run dev
```

开发服务同时提供页面与 `/api/quota`、`/api/models`、`/api/agent`，无需 Python、桌面启动器或另开本地转接程序。

```sh
npm run check
npm test
npm run build
npm run preview
```

`preview` 用于本地检查生产构建，包含这些接口。测试通过模拟上游响应执行，不会调用付费规划或生图接口。

## 使用要点

- **模型**：只导入 GPT Image 系列，按型号适配质量、尺寸和参考图。2.5 可选超清/极致；实际能力、用量与价格取决于 OpenLux 路线。
- **并行生成**：每张独立提交。任务创建后可以继续输入下一次创作；限流有次数上限，超时/断网标记为「结果待核实」。
- **编辑**：「继续改图」使用结果作底图；「导入编辑」恢复原提示词、参数、参考图及蒙版。
- **自然扩图**：默认参考原图与目标布局，使用完整生成画面，避免矩形回贴。可填写新区域内容；原图细节仍可能变化。原图优先模式检查对齐、匹配色调并柔化边缘。
- **本地重新融合**：保存过模型原始结果的扩图可重新自然融合，新增本地版本，不再次请求生成。它不能修复模型原始结果中已经不合理的空间或物件。
- **账户余额**：另填系统访问令牌与数字用户 ID；业务生图 Key 不能代替。默认保存在当前浏览器，可取消记住或清除。顶栏优先显示账户余额，打开页面时刷新一次，没有后台轮询；刷新失败保留旧值并标记。

## 提示词预设与输入区

输入栏的书签按钮打开提示词预设库，也可从「素材与预设」进入。支持新建、编辑、复制、删除与搜索；首次使用加入来自用户所供文档的 10 条可编辑模板。模板被删除后不会在下次刷新时重新出现。

在提示词里用 `[主体]` 或 `{{主体}}` 设置变量。使用时填写变量、查看完整预览，再点击「导入编辑」。可选的“希望避免的内容”会合并为普通文字要求，不会发送不受支持的独立负向参数；平台专属命令不会自动加入。预览显示当前模型的字符预算，超长内容需在导入后精简或切换模型。

普通文字模板保留当前参考图和参数；选中“同时保存参考图与生成参数”可保存完整创作预设。预设保存在浏览器，并包含在完整作品备份中。

使用鼠标时，移入输入框会展开，移出后收回；点击输入框后暂时固定展开，点击外部解除固定并收回。键盘聚焦和触屏点击也可展开，收回不清除草稿。生成按钮以箭头图标显示，悬停说明和无障碍名称保留当前生成动作。

## Agent 模式

输入栏点击 **Agent** 切换，旁边设置按钮配置 OpenLux 规划连接。默认复用生图 Key，规划模型为 `gpt-6.1-sol`；也可填独立 OpenLux Key。输入文字和参考图后，Agent 自动规划参数，必要时补问；方案可编辑，首次确认后才生图。可选择后续在估算费用上限内自动执行。

每个方案最多 1–3 次生图请求。已授权的兼容线路/模型可以在明确失败后自动切换，和参数修正、限流重试共用次数与估算上限。超时、断网、结果不明的 5xx、权限和余额问题不会自动重发。留空费用上限或缺少价格时只能手动确认首次生成。规划文本费用另计，实际账单以 OpenLux 为准。

支持状态卡片、执行轨迹、停止后续步骤、导入输入框编辑、浏览器保存和配置文件迁移。刷新后不自动恢复 Agent 付费请求。设置中的可见性检查不生图；规划测试会产生文本用量。详见 [Agent 使用说明](docs/agent-mode.md)。

## 换电脑时带走连接

Agent 连接也随普通或加密连接 JSON 导入导出；它不进入普通作品备份。

在「连接与偏好 → 跨设备连接」选择「导出连接文件」。新导出的文件包含当前 API 地址、API Key、账户查询令牌、用户 ID、模型清单、生成参数、估算币种和模型价格。换电脑打开本站，把 JSON 拖入顶栏余额左侧的「导入配置」框即可自动填充并保存，也可点击该框或使用设置中的「导入文件」。仅接受 `.json` 扩展名；图片不会触发配置导入。旧版连接 JSON 仍可导入，缺少的模型/价格字段保留当前设置。

普通文件包含明文密钥，请只在自己的设备间保管、传递；需要保护文件时选择「加密导出」，设置至少 8 位密码，导入时解锁一次。加密使用浏览器 Web Crypto 的 AES-256-GCM、PBKDF2-SHA256 和随机盐/IV，文件密码不保存。文件验证失败、密码错误或存储失败不会覆盖原连接。导入不会自动启动旧队列或提交生图任务。

连接文件与作品备份分开：连接文件不包含作品；完整作品备份不包含密钥。导入会清除该账户的旧余额缓存，并自动执行一次模型列表与账户余额的只读刷新；失败会显示提示并保留已保存的配置。价格为文件中携带的个人估算设置，不会被模型列表刷新覆盖。

## 界面与动效

- 顶部导航、图库和输入框使用共同的内容栅格，最大 1440px；宽屏三列、中屏两列、小屏一列，支持短横屏和安全区。
- 进入页面时先显示 Logo，再通过短暂模糊渐显进入工作室；初始化异常有自动解除遮罩的兜底。
- 弹窗、选择菜单、页签、参数选中块、作品位置变化、生成状态及输入区收放采用轻量过渡。参数面板和素材库保持稳定外框，长内容在内部滚动。
- 遵循系统「减少动态效果」偏好，取消进站序列、空间位移和选中块滑动，保留简短的状态反馈。

## 从桌面单文件迁移

浏览器数据按站点隔离。原来的本地 HTML、Vercel 预览域名和正式域名之间不会自动共享历史与凭据。

先在旧工具「素材与预设 → 用量与备份」导出**完整 JSON 备份**，再到新站点导入。备份包含作品、素材、草稿和参数，不含 API Key 或账户查询令牌；凭据可通过「连接配置文件」单独迁移，也可重新填写。建议确定正式域名后再长期使用，换浏览器或清理站点数据前也先导出备份。

图片与历史保存在本浏览器的 IndexedDB；本项目不提供服务器端图片存储或多设备同步。
