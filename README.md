# GPT Image 个人工作室

使用自己的 OpenLux Key 生成、编辑和管理图片。浅色界面，支持参考图拖入/粘贴、并行任务、失败重试、版本分支、局部蒙版、自然扩图、项目/预设、对比与导出。

## 部署到 Vercel

1. 在 Vercel 中导入本仓库。
2. Root Directory 保持仓库根目录，Framework 选择 **Vite**。
3. 构建命令 `npm run build`，输出目录 `dist`，安装命令 `npm ci`。仓库内的 `vercel.json` 已配置这些值。
4. Node.js 选择 **22.x**，然后部署。
5. 打开站点，在「连接与偏好」填写自己的 API Key。默认地址为 `https://api.openlux.ai/v1`。

**不需要把 API Key 或账户查询令牌配置为 Vercel 环境变量，也不要写入源代码。** 每个浏览器使用自己填写的连接。官方地址的模型列表和额度查询通过本站的两个服务端接口转发；凭据仅用于本次查询，应用不在服务端存储或记录凭据。模型输入与图片生成直接从浏览器发往填写的服务商。

Vercel 的函数请求/响应大小存在限制，因此图片上传、生成和下载没有经过函数转发；自定义服务商需要允许浏览器跨域连接。大尺寸图片或复杂生成的等待时长由输入区「任务」设置控制，超时与断网不会自动重复付费生成。[Vercel 函数限制](https://vercel.com/docs/functions/limitations)

## 本地开发

```sh
npm ci
npm run dev
```

开发服务同时提供页面与 `/api/quota`、`/api/models`，无需 Python、桌面启动器或另开本地转接程序。

```sh
npm run check
npm test
npm run build
npm run preview
```

`preview` 用于本地检查生产构建，两个只读查询接口也可使用。测试通过模拟上游响应执行，不会调用付费生图接口。

```text

src/
  main.js                 页面启动入口与样式装配
  app.js                  初始化、历史恢复与页面生命周期
  core/                   状态、浏览器存储、图片 Blob、基础工具
  services/               连接、模型能力、图片请求、账户与价格
  features/               输入区、参考图、任务、图库、素材库、对比、导出、编辑与扩图
  ui/                     对话框、浮层和自定义选择器
  styles/                 基础与各类组件样式
  assets/icons.svg        图标符号
public/favicon.svg
index.html
vite.config.js

tests/                    只读接口与连接文件测试；不是线上测试入口
```

没有 `/api/health`、调试接口、任意地址代理、测试密钥、旧版 HTML 备份、测试图片或 Windows 启动器。前端使用 ES Modules，没有把应用状态或调试函数挂到 `window`。

## 使用要点

- **模型**：只导入 GPT Image 系列，按型号适配质量、尺寸和参考图。2.5 可选超清/极致；实际能力、用量与价格取决于 OpenLux 路线。
- **并行生成**：每张独立提交。任务创建后可以继续输入下一次创作；限流有次数上限，超时/断网标记为「结果待核实」。
- **编辑**：「继续改图」使用结果作底图；「导入编辑」恢复原提示词、参数、参考图及蒙版。
- **自然扩图**：默认参考原图与目标布局，使用完整生成画面，避免矩形回贴。可填写新区域内容；原图细节仍可能变化。原图优先模式检查对齐、匹配色调并柔化边缘。
- **本地重新融合**：保存过模型原始结果的扩图可重新自然融合，新增本地版本，不再次请求生成。它不能修复模型原始结果中已经不合理的空间或物件。
- **账户余额**：另填系统访问令牌与数字用户 ID；业务生图 Key 不能代替。默认保存在当前浏览器，可取消记住或清除。顶栏优先显示账户余额，打开页面时刷新一次，没有后台轮询；刷新失败保留旧值并标记。

## 换电脑时带走连接

在「连接与偏好 → 跨设备连接」选择「导出连接文件」。文件包含当前 API 地址、API Key、账户查询令牌与用户 ID；换电脑打开本站，把这个 JSON 文件拖入页面即可恢复并默认保存到当前浏览器，也可用「导入文件」选择。

普通文件包含明文密钥，请只在自己的设备间保管、传递；需要保护文件时选择「加密导出」，设置至少 8 位密码，导入时解锁一次。加密使用浏览器 Web Crypto 的 AES-256-GCM、PBKDF2-SHA256 和随机盐/IV，文件密码不保存。文件验证失败、密码错误或存储失败不会覆盖原连接。导入只恢复连接，不会自动启动旧队列或提交生图任务。

连接文件与作品备份分开：连接文件不包含作品；完整作品备份不包含密钥。导入连接会清除该账户的旧余额缓存，并尝试进行一次只读刷新。

## 界面与动效

- 顶部导航、图库和输入框使用共同的内容栅格，最大 1440px；宽屏三列、中屏两列、小屏一列，支持短横屏和安全区。
- 进入页面时先显示 Logo，再通过短暂模糊渐显进入工作室；初始化异常有自动解除遮罩的兜底。
- 弹窗、选择菜单、页签、参数选中块、作品位置变化、生成状态及输入区收放采用轻量过渡。参数面板和素材库保持稳定外框，长内容在内部滚动。
- 遵循系统「减少动态效果」偏好，取消进站序列、空间位移和选中块滑动，保留简短的状态反馈。

## 从桌面单文件迁移

浏览器数据按站点隔离。原来的本地 HTML、Vercel 预览域名和正式域名之间不会自动共享历史与凭据。

先在旧工具「素材与预设 → 用量与备份」导出**完整 JSON 备份**，再到新站点导入。备份包含作品、素材、草稿和参数，不含 API Key 或账户查询令牌；凭据可通过「连接配置文件」单独迁移，也可重新填写。建议确定正式域名后再长期使用，换浏览器或清理站点数据前也先导出备份。

图片与历史保存在本浏览器的 IndexedDB；本项目不提供服务器端图片存储或多设备同步。
