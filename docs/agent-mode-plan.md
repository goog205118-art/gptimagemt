# Agent 模式实施方案

第一版已按本方案实现。实际操作、边界和验证范围见 [Agent 使用说明](agent-mode.md)。本文保留规划与执行规则，分阶段条目作为实现及验收依据；没有使用真实 Key 验证服务商账户权限。

## 适合本工具的工作方式

在输入框增加「手动 / Agent」切换。Agent 接收文字与参考图，整理用途、主体、参考关系和必须保留的内容，选择生图模型、比例、质量、张数，交给现有生成队列执行。现有手动编辑、预设、任务卡片和素材导入继续共用。

规划模型使用 `gpt-6.1-sol`。官方支持文字和图片输入，以及通过 Responses API 使用工具；实际接入仍须验证服务商是否提供同名模型、图片输入、Responses 和所需结构化输出能力。不能因为图片 Key 能生成图片，就认定它也支持规划模型。

参考：[模型文档](https://developers.openai.com/api/docs/models/gpt-6.1-sol)、[Responses API](https://developers.openai.com/api/reference/responses/overview)、[结构化输出](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)。

## 用户流程

1. 输入需求、添加参考图，提交后出现「理解需求」卡片。
2. 只有影响结果的歧义才提问。例如：主参考图是哪张、是否必须保留产品结构、用于横版封面还是竖版海报。每轮最多 3 个问题，优先提供选项，也允许文字补充。常规参数使用已保存偏好和合理默认值。
3. 显示简短方案：采用模型、画幅、质量、张数、参考图用途和预计费用；可直接调整。首次确认方案，之后可开启在指定预算内自动执行。
4. 同一张任务卡片展示规划、等待补充、排队、生成、调整方案、成功或失败。用户可中止后续步骤、导入方案继续手动编辑。
5. 图片成功后默认结束。第一版不自动循环“审美打分—重新生成”，避免不可控费用。

## 规划与执行边界

- 规划输出采用结构化字段：操作类型、提示词、参考图 ID 与用途、保留约束、模型、尺寸、质量、数量、待补充问题。
- 模型只从当前可用的 GPT 生图清单中选择。执行器根据现有能力矩阵重新验证参数、提示词长度、参考图、蒙版、透明背景和分辨率；规划模型不能跳过验证。
- 规划模型只接收必要的压缩参考预览；生图仍使用原始素材。图片和提示词中的文字视为素材内容，不能修改密钥、预算、目标域名或执行规则。
- 路由与候选模型必须来自用户配置和已验证清单。禁止模型自己拼接任意地址、执行脚本或读取其他密钥。
- 每个任务保存规划、执行参数和请求记录；密钥不写入任务记录或普通素材备份。

## 连通性与自动恢复

模型列表、余额查询成功只代表相应接口可访问，不能证明某个生图模型、路由或蒙版功能可用。分别记录模型 × 路由 × 操作（文生图、编辑、蒙版）的实际成功率、失败类型和耗时；不在后台自动生成测试图。

自动恢复只能用于结果明确且不违反用户要求的失败：

| 情况 | 执行动作 |
| --- | --- |
| 明确拒绝的参数错误 | 修正已识别的不兼容参数，最多一次；不删除必要参考或保留约束 |
| 明确的模型或线路不可用，且确认未创建任务 | 换已配置的兼容线路；仍失败再换兼容模型 |
| 429 限流 | 按服务端等待时间退避，并限制次数；不连续切线路轰炸 |
| 401/403、余额不足、内容拒绝 | 停止并解释，不靠切换模型规避 |
| 超时、网络断开、结果不明的 5xx | 标记「结果待核实」，不自动重发；如有任务查询接口或幂等机制，先核实原任务 |
| 已生成，但图片下载或本地处理失败 | 重试读取或处理已有结果，不重新生成 |

候选模型必须支持当前参考图、蒙版、透明背景和目标分辨率。无法满足时，询问是否允许降级；不能静默删除素材、降低必要质量或更改创作目标。

第一版建议每个方案最多 2 轮规划补充、3 次生图请求（含修参、重试及切换），并设预计费用上限。所有重试共用同一上限。若服务商没有准确价格，仅能展示估算；余额变化也不能用来证明某一任务的结果。

关闭页面、刷新或取消等待，不代表服务商任务已取消；恢复页面后先核实进行中任务，不自动重启。

## 分阶段实施

1. **接入验证**：设置独立 Agent 地址、模型 ID 和 Key；先验证服务商兼容性，再做一次有预算的规划及生图验收。若无 Responses 工具调用能力，重新评估适配方式，不默认替换规划模型。
2. **规划与补问**：实现结构化规划、卡片状态和小问题框，复用现有参数验证与参考图系统。先采用方案确认后执行。
3. **受控自动执行**：加入统一请求/费用上限、授权候选列表、失败分类、线路冷却、结果核实和恢复记录。
4. **验收**：模拟参数错误、限流、线路失效、权限错误、超时、刷新和取消；确认没有重复提交、参考图丢失或静默降级。少量真实请求单独计入用户确认的预算。

Vercel 可承载规划请求的服务端转发；图片生成继续使用现有队列。若以后需要关网页后持续运行，应增加持久任务队列，不能让一个普通网页或短时函数承担长期后台任务。
