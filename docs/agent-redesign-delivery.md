## 验证

`npm run check`、`npm test`、`npm run build` 均通过，共 48 项测试；新增要求、继承、操作约束、自动授权、输出检查、部分完成与恢复测试。原有预算、兼容回退、429、权限、5xx、连接文件与图片输入测试保留。

`scripts/agent-smoke.mjs` 使用隔离的无头 Edge 与完全模拟的规划/生图响应，禁止访问真实服务商。18 项场景通过，覆盖版本绑定、双击去重、要求漂移拦截、条件变更撤销核对、关闭表单后恢复、图库位置稳定、Escape 收起与焦点返回、本地裁切零请求、蒙版、扩图布局、输出尺寸不符、高清局部参考、429 共享预算、明确拒绝后的兼容回退、不明 503 不重试、断网与刷新、旧备份导入及续改。可在安装 Playwright 的环境使用：

```sh
npm run build
npm run preview -- --port 4173
# 在另一个终端，确保 playwright 可通过本机安装或 NODE_PATH 解析

```

## 尚待真实验证的部分

- A01–A08 使用上述模拟与代码测试验证关键路径，不能据此证明 OpenLux 当前账户、线路能力或账单行为。
- A09 真实成图对照尚未执行，没有使用真实 Key 或测试预算。仍需同素材、同线路对照手动、旧 Agent 和新版的首轮可用率、返工、时间与费用。
- P3 的 OCR / 视觉评审、多规格批量交付未开启；本次局部、裁切、扩图每轮交付一个版本。
- 画幅调整通过用户预览裁切或确认扩图布局判断主体保留范围，未声称自动识别安全裁切边界。
- 要求提取采用有限规则并完整保留原始请求，不能覆盖所有自然语言表达；涉及继承的 Logo、文字、结构等变更时保守要求人工核对。
- 精确文字原文可追溯，但生图无法保证字形、Logo 或结构一致；项目没有新增可编辑文字图层，建议交给现有桌面排字流程。

## 界面复核

后续修复：多张变体原先重复公共提示词，可能把“生成三张及三套设计”一并传给每个请求。现已拆为单张共同要求、变化维度及逐张差异；逐张预览使用实际请求构建函数，实际请求与变体写入日志。AI 根据图片内容与用途提供内容类型、推荐维度、理由和具体细节，用户选定后生成，默认不勾选；切换维度或重新规划会清空选择，关闭再打开保留选择与编辑。自动执行同样等待变体选择。只选一项就只创建一个任务。

已设置的变化维度/各行内容进入规划上下文和要求冲突检查；变体修改会撤销确认。旧多张方案阻止直接重发，转手动使用每行一张。新增 5 项测试，当前共 53 项通过；模拟浏览器共 26 项场景，包括逐张隔离、推荐选择、单项交付、自动执行等待选择、预览与实际请求一致、旧批次指令零请求拦截和转手动数量验证。局部编辑与扩图也对照实际发送提示词，修正了预览遗漏父版本场景信息的问题；检查选中子版本时继承的根版本场景一致。提示词语义检查为有限规则，内容类型及理由是模型建议，模拟验收不证明真实模型一定遵循要求。
